最后约 75 秒，私有内存为 92,295,168 bytes、句柄为 345；最后约 44 秒 GPU shared 为 62,083,072 bytes。working set 最后 30 秒仅增加 8192 bytes。此次没有按重复操作持续累积整套 buffer 规模的增长迹象。

## 范围与决定

CSV 没有操作阶段标记或 viewport 几何数据，不能机械验证三轮操作已严格完成，也不能把某个时点直接标成缩放、停靠或回收完成。因此本报告是有限完整应用资源趋势观察，不是逐周期泄漏门禁。GPU 性能计数器的共享计数及已知误报限制沿用[采样说明](20260912-bounded-lifetimes.md#2026-09-16完整应用资源观察准备)。
