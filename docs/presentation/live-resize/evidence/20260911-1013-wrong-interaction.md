no detached resize or replacement coverage, so merely adding final snapshots would
not turn this pair into a meaningful performance comparison. No latency percentile
comparison is reported for resize. No conclusion is drawn about improvement or
regression from the differing idle-frame counts.

The recorder can expire while the UI thread is in a native modal loop with no active
RenderFrame tail; the frame-finalization guard then cannot emit boundary closure.

Confirm the interaction target before requesting another run. The independent
Spectrum viewport existed in both captures, so this is not evidence that detachment
failed entirely.
