# Triage labels

This repository uses the following five canonical triage label names. They are
the workflow vocabulary; a GitHub label may be created when the corresponding
state is first needed rather than all labels existing in advance.

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer needs to evaluate the issue. |
| Needs information | `needs-info` | Waiting for more information. |
| Ready for agent | `ready-for-agent` | Fully specified and suitable for AFK implementation. |
| Ready for human | `ready-for-human` | Requires human implementation or decision. |
| Won't fix | `wontfix` | Will not be actioned. |

Use the exact strings above when applying triage labels. Do not introduce a
second spelling for the same workflow state.
