# Domain docs

SpecForge is a single-context repository.

Before exploring a domain change, read the relevant sections of the root
`CONTEXT.md` and any applicable files under `docs/adr/`. Use the glossary terms
defined in `CONTEXT.md` in issue titles and descriptions. In particular,
distinguish a source collection, spectrum snapshot, sample navigation, sample
annotation, spectral-line marker, and public spectral-line catalog.
